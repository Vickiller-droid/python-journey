# python-journey

A small collection of Python example scripts and exercises.

## Files
- `hello`: [hello.py](hello.py) — simple greeting example.
- `calculator`: [calculator.py](calculator.py) — basic calculator functions.
- `check`: [check.py](check.py) — small utility or test script.
- `lists`: [lists.py](lists.py) — examples working with lists.

## Usage
- Run hello: `python3 hello.py`
- Run calculator: `python3 calculator.py`
- Run check: `python3 check.py`
- Run lists: `python3 lists.py`
